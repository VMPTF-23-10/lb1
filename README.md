# Лабораторна робота: Django + Python

Сайт для перегляду та додавання курсів валют до гривні.

## Запуск проєкту

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

Після запуску сайт доступний за адресою:

```text
http://127.0.0.1:8000/
```

## Адмін-панель

Адмін-панель доступна за адресою:

```text
http://127.0.0.1:8000/admin/
```

Щоб увійти в адмін-панель, потрібно створити адміністратора:

```powershell
.\.venv\Scripts\python.exe manage.py createsuperuser
```

В адмін-панелі можна додавати, редагувати та видаляти валюти і курси валют.

Спочатку адміністратор додає доступні валюти, наприклад:

```text
USD - Долар США
EUR - Євро
PLN - Польський злотий
```

Після цього на головній сторінці сайту ці валюти з'являться у випадаючому списку.
Звичайний користувач не вводить назву валюти вручну, а тільки вибирає валюту зі списку.

## API

Актуальні курси валют за сьогодні доступні у форматі JSON:

```text
http://127.0.0.1:8000/api/rates/today/
```

Приклад відповіді:

```json
{
  "date": "2026-05-01",
  "rates": [
    {
      "name": "USD",
      "buy_rate": "40.10",
      "sell_rate": "40.60"
    }
  ]
}
```
